# 建模文档骨架（浓缩一屏）

> 落盘路径：`notes/Invariants/<组件>.md`
> 硬性要求：**一屏内读完**；用表格不用散文。宁可省略解释，不可省略**检测器**与**豁免理由**。
> 表达要求：标题可括注人话；对用户汇报先讲人话再上术语。
> 只有三段是主体：**C 契约 / I 不变量 / X 豁免**；其余能省则省。

## 填写规则

- **I 检测器列**必须写得出「什么断言、怎么受控交错、坏实现上如何变红」，否则该不变量未定义。
- **X 每行**必须有理由 + 风险；有前提假设的再给「假设守卫」（可执行断言）。
- **机制选择**给 2–3 个候选 + 各自失败时序，收敛到 1 个。
- 文档不设「待拍板 / 已拍板」状态字段——人直接在对话里确认。
