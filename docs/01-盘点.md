# NitroGateway 盘点(阶段 1)

> 生成时间: 2026-08-04 | 运行基线已验证: 构建 ✅ 测试 ✅ 启动 ✅(MQTT 依赖 Degraded)

## 一句话

工业物联网边缘网关:PLC 采集(Modbus/S7 等) → 本地 SQLite → MQTT 转发云端 → Vue 3 管理面板。

## 技术栈与关键依赖

| 层 | 技术 | 版本/说明 |
| --- | --- | --- |
| 运行时 | .NET | 10(SDK 10.0.301) |
| Web | ASP.NET Core Web API | REST + SignalR + HealthChecks |
| 数据库 | SQLite | EF Core + Dapper + FluentMigrator 迁移 |
| 消息 | MQTTnet | broker: eclipse-mosquitto:2(docker) |
| 指标 | prometheus-net | 8 个指标 |
| 日志 | Serilog | 结构化 JSON, Console + File 日轮转(保留 7 天) |
| 校验 | FluentValidation | WriteGuard 三级门控 |
| 前端 | Vue 3 + Element Plus + ECharts + SignalR | vue ^3.5.34 / element-plus ^2.14.2 / echarts ^6.1.0 / pinia ^3.0.4 |
| 前端构建 | Vite 8 + TypeScript 6 + vue-tsc | node_modules 已安装 |
| 部署 | Docker + docker-compose | 三服务: mqtt / gateway / web |

## 启动/测试/构建命令

```bash
# 1. 启动 MQTT broker
docker compose up -d

# 2. 后端(端口 5100)
cd src/NitroGateway.Webapi && dotnet run

# 3. 前端(端口 5173)
cd web && npm install && npm run dev

# 4. 验证
# 前端: http://localhost:5173   登录 admin/admin123
# API:  http://localhost:5100/swagger
# 指标: http://localhost:5100/metrics
# 健康: http://localhost:5100/healthz  /readyz

# 构建 / 测试
dotnet build NitroGateway.slnx
dotnet test tests/NitroGateway.UnitTests
```

## 入口点与配置

- 入口: `src/NitroGateway.Webapi/Program.cs`(ASP.NET Core Host)
- 配置: `src/NitroGateway.Webapi/appsettings.json`
  - `Urls`: http://localhost:5100
  - `Persistence__ConnectionString`: `Data Source=nitrogateway.db`(相对 Webapi 工作目录, FluentMigrator 自动建库)
  - `MQTT`: localhost:1883, KeepAlive 60s, 最大重连 10 次, 退避 1s→30s
  - `Security`: JWT 8h;内置用户 admin/admin123(Admin)、operator/oper123(Operator)、viewer/view123(Viewer)
- 部署配置: `docker-compose.yml`(mqtt/gateway/web 三服务, 生产 JWT_SECRET 环境变量, 数据卷 gateway-data/gateway-logs), `Dockerfile`(多阶段, .NET 10)
