# NitroGateway 架构理解(阶段 2)

> 生成时间: 2026-08-04 | 基于代码抽查 + README 交叉验证

## 分层架构

```
表现层   Webapi: REST API + SignalR(/hubs/live) + Swagger + HealthChecks + AuditMiddleware
编排层   Host: GatewayLifecycle(优雅关闭 drain)
应用层   Collection(采集) / Forwarder(转发) / Device(设备+健康) / Alarm(告警)
基础设施 Persistence(SQLite) / Protocol(Modbus/S7) / Transport(MQTT/HTTP) / Telemetry / Security / Storage(纯接口)
领域层   Domain: 设备、点位、快照、协议抽象 / Shared: OperationResult
```

单向依赖,无循环引用;Webapi 为唯一组合根(Program.cs 注册全部模块)。

## 核心数据流

```
Modbus TCP PLC(:502)
  → DeviceReader(3 次重试 + 指数退避)
  → PointValuePipeline(类型转换 → 工程缩放 → 死区过滤)
  → DataDispatcher(双写: SQLite MeasurementStore + ForwardBuffer)
      ├─ SQLite(本地时序)
      └─ ForwardBuffer(FIFO, 两阶段提交, InFlight 防重)
  → ForwarderEngine(5s 周期)
  → Forwarder(Dequeue → JSON 序列化 → MQTT Publish → Commit)
      └─ 失败 → retry_count+1 → ≥上限 → 直接丢弃(dropped 指标)
```

## 关键机制

| 机制 | 位置 | 行为 |
| --- | --- | --- |
| 熔断器 | Collection/Resilience/CircuitBreaker.cs | 每设备独立; Closed→(5 连败)→Open→(30s)→HalfOpen→探测; 冷却翻倍上限 5min |
| 转发批量上限 | Forwarder/Forwarder.cs | 单次出队固定上限 MaxDequeuePerCall=1000(简化 2026-08-22, 删 AIMD 节流) |
| 重试超限丢弃 | Persistence Sqlite + Forwarder | Pending→InFlight→Commit/删除 或 MarkFailed(重试+1回 Pending); 超限直接 DELETE 丢弃 + 指标 dropped |
| 设备健康 | Device/Listeners | HealthMonitor 为单一权威源(SST); 3 连败 Offline / 3 连胜 Online; 事件驱动写库/重置 CB/推 SignalR |
| 告警引擎 | Alarm | 7 种比较操作符 + Duration 去抖(回落重置) + 生命周期 Pending→Active→Acknowledged→Resolved + Active 去重; 通知走 IAlarmNotifier(MQTT 实现,可插拔) |
| 配置热加载 | Device + Webapi | API 改配置 → DB 保存 → StatusChanged 事件 → DeviceCache 内存更新, 下一采集周期生效, 不中断当前轮 |

## 外部依赖

- MQTT Broker: eclipse-mosquitto:2, localhost:1883(docker compose)
- Modbus PLC / 模拟器: 端口 502(TCP), 或 RTU 串口
- SQLite: 单文件, FluentMigrator 自动建表迁移
- 前端构建: Node + npm(已装 node_modules)

## 模块边界要点(修改雷区)

- Storage 是纯接口层,实现仅在 Persistence;新存储实现不得改接口层(接口只增不删)
- Protocol 用复合工厂(Protocols)按设备类型创建驱动;新协议 = 新增 Abstractions 实现 + 工厂注册
- Domain 不引用任何基础设施;跨模块通信走事件(Domain/Events)或接口
- 采集与转发解耦: 转发失败不影响采集(SQLite 先落库)
- 熔断器与健康监控互不控制: CB 是门控(能不能连), HM 是判定(值不值得信任)
