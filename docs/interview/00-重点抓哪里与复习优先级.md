# 重点抓哪里：项目导向的面试复习优先级（2026-08-20）

> 场景：非应届（毕业 2 年、无相关开发经验），以 NitroGateway 完整作品集（.NET 10 工业物联网边缘网关 + Vue3/WPF 双端 + 726 单测 + Docker Compose 部署）应聘「经验不限 / 初级 / 应届可投」的物联网/数采、上位机、初级 .NET 岗。
> 一句话判断：面试官唯一能信你的 = **① 基础扎实 ② 作品讲得透**。所以重点不是补没见过的东西，而是把项目里**已有、且正好是 JD 要的**练到能深挖三层。

## 一、三大重点（按 ROI 排序）

### 1. 工业协议 —— 你的锚（决胜点）
| 协议 | 定位 | 可讲素材（代码/ADR） | 注意 |
|---|---|---|---|
| Modbus | **基本盘**。JD 常见「Modbus/OPC UA/Fins 至少一种」 | 功能码 01/03/04/05/06/0F/10、四类寄存器（线圈/离散/保持/输入）、RTU CRC、TCP 帧；批量读 `ModbusBatchPlanner`、串口多从站共享 `SerialPortManager`（`src/NitroGateway.Protocol/Modbus/`） | 题库 `docs/interview/protocol/` 现成，先刷透 |
| MQTT | **深度题**。最能证明「你真的做过」 | QoS 1 发布成功才 Commit 删除、两阶段出队、失败重试超限即丢弃、固定批量上限 ≤1000（2026-08-22 删 AIMD/死信）（`src/NitroGateway.Forwarder/`；ADR-001） | 讲「为什么这样设计」的故事，别背概念 |
| OPC UA | 加分项（刚实现并实测） | NodeId 四型、订阅 vs 轮询、证书互认、断链重连（进程内 Server 冒烟实测） | **边界（ADR-060）**：Browse 节点树、证书落地未做；被深挖要诚实说「初版，下一步做 Browse」 |

### 2. 系统设计故事 —— 无经验最怕的深挖，你有 ADR 弹药
每个按「**问题 → 定位 → 修法 → 测试**」讲，能报 726 单测：

1. **断网数据怎么不丢**：SQLite 转发缓冲 + 断点续传（ADR-001）
2. **采集挂了怎么自愈**：熔断 + 半开探测 + 优雅关闭 drain（ADR-016 P1-1、CircuitBreaker）
3. **云端恢复怎么不冲垮**：固定批量上限 ≤1000 排水 + MQTT 总开关（2026-08-22 删 AIMD；ADR-059）

### 3. WPF / 上位机差异化 —— 你的第二张牌（投上位机时）
404 个 WPF 文件里，**别陷进 UI 打磨细节**（ADR-037~051 大多是样式/视觉，面试不问圆角）。只备 3 点：
- **MVVM**（View/ViewModel 分层，`src/NitroGateway.Desktop/ViewModels/`）
- **实时刷新不卡 UI 的线程模型**：QueryLatest 移出 UI 线程（ADR-047）、切换设备卡顿根因（ADR-050）
- **串口 / Modbus 通讯** + 多线程（Task/async-await/SemaphoreSlim/Channel，项目里有实景）

## 二、别花太多时间的陷阱
- **通用 .NET 八股**（string/LINQ/GC/DI 生命周期）：保底但同质化，不是赢点；每天固定量，别让它主导复习
- **补 S7 批量读等性能优化**（ADR-042 #1）：纯技术优化，面试/简历价值低，缓
- **WPF 样式打磨**：上位机面试官关心「卡不卡、线程对不对」，不关心边框圆角
