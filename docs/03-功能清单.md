# NitroGateway 功能清单(阶段 2)

> 生成时间: 2026-08-04 | 基于代码(Controllers/后台服务/前端路由)

## 设备与点位管理

- [F-01] 设备 CRUD: GET/POST/PUT/DELETE `/api/devices`、GET `/api/devices/{id}`
  - 位置: src/NitroGateway.Webapi/Controllers/DevicesController.cs
  - 依赖: IDeviceManager(Device 模块) + SQLite
- [F-02] 设备启停: PUT `/api/devices/{id}/status`
  - 位置: DevicesController.cs; 依赖: DeviceManager 状态门控
- [F-03] 点位 CRUD: GET/POST/PUT/DELETE `/api/devices/{deviceId}/points[/{pointId}]`
  - 位置: DevicesController.cs; 依赖: IPointManager
- [F-04] 连接测试: POST `/api/devices/test-connection`
  - 位置: DevicesController.cs
- [F-05] 串口枚举: GET `/api/devices/serial-ports`、`/serial-port-status`
  - 位置: DevicesController.cs; 依赖: 系统串口(RTU 用)
- [F-06] CSV 点位导入/导出/批量生成: POST `/api/point-import/import`、`/generate`、GET `/export`
  - 位置: Controllers/PointImportController.cs; 依赖: PointBatchService
- [F-07] 测量查询: GET `/api/measurements/history`、`/latest`、`/latest-batch`
  - 位置: Controllers/MeasurementsController.cs; 依赖: IMeasurementStore

## 采集链路

- [F-08] 定时采集引擎: 1s 周期, 并发上限 SemaphoreSlim(5)
  - 位置: src/NitroGateway.Collection/CollectionEngine.cs
- [F-09] 设备读取与重试: 3 次重试 + 指数退避
  - 位置: Collection/DeviceReader/DeviceReader.cs
- [F-10] 点位处理管道: 类型转换 → 工程缩放 → 死区过滤
  - 位置: Collection/Pipeline/PointValuePipeline.cs
- [F-11] 数据双写分发: SQLite MeasurementStore + ForwardBuffer
  - 位置: Collection/Dispatcher/DataDispatcher.cs
- [F-12] 熔断器: 每设备独立, Closed/Open/HalfOpen, 冷却翻倍上限 5min
  - 位置: Collection/Resilience/CircuitBreaker.cs

## 转发链路

- [F-13] MQTT 转发引擎: 5s 周期, Dequeue→Serialize→Publish→Commit
  - 位置: src/NitroGateway.Forwarder/ForwarderEngine.cs
- [F-14] 自适应节流: AIMD, batch 100~1000, delay 0~200ms
  - 位置: Forwarder/ForwardingThrottle.cs
- [F-15] 死信队列: retry≥5 → DeadLetter; GET/POST retry/DELETE `/api/deadletters[/{batchId}]`
  - 位置: Controllers/DeadLettersController.cs + Forwarder/Forwarder.cs
- [F-16] MQTT 连接管理: 重连退避 1s→30s, 上限 10 次, TLS 可选
  - 位置: src/NitroGateway.Transport/MQTT/MqttHostedService.cs

## 告警

- [F-17] 告警规则 CRUD: GET/POST/PUT/DELETE `/api/alarm-rules[/{id}]`
  - 位置: Controllers/AlarmRulesController.cs
- [F-18] 告警评估: 7 种操作符 + Between, Duration 去抖, Active 去重
  - 位置: src/NitroGateway.Alarm/Evaluation/
- [F-19] 告警查询/确认: GET `/api/alarms`、`/device/{deviceId}`、GET `/history`、POST `/{alarmId}/ack`
  - 位置: Controllers/AlarmsController.cs
- [F-20] 告警通知: MQTT 推送, IAlarmNotifier 可插拔(钉钉/企微/邮件扩展点)
  - 位置: Alarm/Notification/

## 健康与监控

- [F-21] 设备健康监控: 3 连败 Offline / 3 连胜 Online, 初始 Unknown
  - 位置: src/NitroGateway.Device/Listeners/ + HealthMonitor
- [F-22] 状态面板: GET `/api/status/system`、`/devices`、`/devices/health`
  - 位置: Controllers/StatusController.cs
- [F-23] Prometheus 指标: GET `/metrics`(nitro_collection_total 等 8 个)
  - 位置: src/NitroGateway.Telemetry/
- [F-24] 健康检查: `/healthz`(全量) + `/readyz`(db+ready 标签)
  - 位置: src/NitroGateway.Webapi/Program.cs + HealthChecks/(SqliteHealthCheck, MqttHealthCheck)
- [F-25] 全链路追踪: Activity, 8 个 Span
  - 位置: Telemetry/Tracing/

## 安全

- [F-26] 登录签发 JWT: POST `/api/auth/login`(8h 过期)
  - 位置: Controllers/AuthController.cs; 依赖: Security/Auth
- [F-27] RBAC: Admin/Operator/Viewer, 5 个授权策略, Controller 级 [Authorize(Roles=...)]
  - 位置: src/NitroGateway.Security/
- [F-28] 写校验 WriteGuard: 设备模式 + 值范围 + 变化率三级门控
  - 位置: Security/(FluentValidation)
- [F-29] 审计: AuditMiddleware 记录所有 /api/* 访问
  - 位置: Program.cs + Security/Audit/
- [F-30] SignalR 实时推送: `/hubs/live`, JWT 经 query string
  - 位置: Webapi/Hubs/LiveDataHub.cs + OutboxConsumer.cs
