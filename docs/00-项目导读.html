一句话简介

工业物联网边缘网关:从 PLC 采集数据(Modbus/S7) → 本地 SQLite 存储 → MQTT 转发到云端 → Vue 3 管理面板实时监控。

核心卖点:断连自动恢复(熔断器)、数据不丢(两阶段提交缓冲)、转发自适应节流(AIMD)、8 小时长稳。

怎么跑

docker compose up -d                       # 1. MQTT broker
cd src/NitroGateway.Webapi && dotnet run   # 2. 后端 :5100
cd web && npm install && npm run dev       # 3. 前端 :5173
# 登录 admin/admin123
# API: http://localhost:5100/swagger   指标: /metrics   健康: /healthz /readyz
dotnet test                                # 单元测试(115 通过)

技术栈

层技术
运行时.NET 10 / ASP.NET Core Web API
数据库SQLite(EF Core + Dapper + FluentMigrator)
消息MQTTnet(Mosquitto broker)
观测Prometheus 指标 + Serilog + Activity 追踪
安全JWT + RBAC(Admin/Operator/Viewer) + WriteGuard + 审计
前端Vue 3 + Element Plus + ECharts + SignalR(Vite 8)
部署Docker + docker-compose(3 服务)

架构

领域层 Domain/Shared
  ↓
应用层 Collection(采集) / Forwarder(转发) / Device(设备+健康) / Alarm(告警)
  ↓
基础设施 Persistence(SQLite) / Protocol(Modbus/S7) / Transport(MQTT/HTTP)
         Telemetry(指标/追踪) / Security / Storage(纯接口)
  ↓
编排层 Host(优雅关闭)  →  表现层 Webapi(REST + SignalR + Swagger)

数据流: PLC → DeviceReader(重试) → PointValuePipeline(转换/缩放/死区)
      → DataDispatcher 双写 → SQLite + ForwardBuffer
      → ForwarderEngine(5s) → MQTT Publish → 失败重试 → ≥5 次进死信

关键机制

  • 熔断器:每设备独立, 5 连败 Open → 30s 冷却 → HalfOpen 探测, 冷却翻倍上限 5min
  • 转发节流:AIMD 算法, batch 100~1000 / delay 0~200ms 自适应
  • 死信队列:Pending→InFlight→Commit, retry≥5 进死信, 可重放/丢弃
  • 健康监控:3 连败 Offline / 3 连胜 Online, 事件驱动写库 + 重置熔断器 + 推前端
  • 告警:7 种操作符 + Duration 去抖 + 生命周期(Pending→Active→Ack→Resolved) + Active 去重
  • 配置热加载:API 改配置 → 事件 → 内存缓存, 下一采集周期生效, 不中断当前轮
