## 1. 一句话复盘

从 2026-06-12 初始化到 2026-08-29，NitroGateway 从一个工业协议网关雏形演进为「采集 → 本地存储 → 可靠上行 → 实时可视 → 告警 → 命令回写闭环」的自治边缘网关：16 个 src 模块 + WPF 桌面端 + Vue web 端，约 326 个 C# 文件，104 个 commit，782 单测 + 51 集成全绿，出厂门禁 P0+P1 通过。

## 3. 关键决策地图（ADR 故事线）

一条线讲完项目：ADR-001(断点续传) → ADR-016(自愈/优雅关闭) → ADR-006(节流) → ADR-012(磁盘保护) → ADR-025/026(双端) → ADR-035(角色拆分) → ADR-053(数据量) → ADR-062(降频) → ADR-059/061(MQTT 开关) → ADR-060(OPC UA + 边界) → ADR-052(生产加固) → ADR-069(回写闭环) → systemd 看门狗。

各决策要点（详见 02/03 文档与 notes/ADR 导航）：

| 主题 | 决策 | 结果 |
| --- | --- | --- |
| 数据可靠性 | 两阶段提交 outbox + 重试 + 死信（ADR-001） | 断网/断 broker 不丢数，kill 可恢复 |
| 自愈 | 每设备熔断器 + 优雅 drain（ADR-016） | 故障设备隔离，停机排空缓冲 |
| 节流 | 固定批量上限（2026-08-22 起替代 AIMD） | 防 MQTT 恢复瞬间冲垮 broker |
| 磁盘 | 写满前预警 + 降级暂停出队（ADR-012） | 7×24 无人值守不写爆 |
| 架构 | 边缘采集转发 / 中心汇聚展示（ADR-035）；web 纯边缘化（ADR-054） | 边缘自治，中心另立 |
| 数据量 | 死区变化抑制 + 心跳兜底（ADR-053）；点位级降频（ADR-062） | 22GB → 0.6GB 级（按需放行） |
| 控制 | MQTT 转发总开关（ADR-059/061） | 运行期启停上云 |
| 协议 | OPC UA 初版（ADR-060） | 加分项 + 诚实边界（Browse/证书 v2） |
| 生产 | 强制环境变量/拒默认账号（ADR-052） | 生产禁测试账号，未配置拒启 |
| 回写 | 命令处理器（ADR-069） | 云→网关→PLC 闭环 + 幂等 + 回执 |
| 运维 | systemd + 看门狗 | 断电重启自愈、健康自愈 |

## 4. 数据量与性能的故事（面试弹药）

- 死区变化抑制 + 心跳兜底（300s）：值变化超过死区才放行，未变化按心跳周期上报。
- 存储 / MQTT / SignalR 共用同一放行子集，避免三路数据量放大（ADR-053）。
- 点位级 ScanIntervalMs 降频：死字段不必每秒读（ADR-062）。
- 转发固定上限限流：单次出队 ≤1000 批、单轮排水 ≤2000 批；积压上限 100000 批。
- 8h 长稳（T3 门禁）：SQLite 增量 ≤50MB（10 点位 1s）、内存 ≤ 初始 2 倍、数据连续、重启恢复。
