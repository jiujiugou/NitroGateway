## 4. 核心覆盖清单（单元测试）

| 模块 | 覆盖点 |
| --- | --- |
| Collection | PointValuePipeline（缩放/死区/类型转换/点位级降频）、MeasurementWriteHost 异常隔离、CollectionEngine 异常恢复、熔断器三态全路径、健康监控迁移、空点位探活 |
| Forwarder | 两阶段提交、死信阈值、单批失败隔离、MQTT 开关、固定上限出队、JsonMessageSerializer 载荷 |
| Command | 命令解析校验（topic/载荷/非法命令）、幂等（commandId 去重）、写值失败回执、回执序列化 |
| Alarm | ThresholdEvaluator 7 种操作符 + Between、Duration 计时/回落重置、去重、多规则 |
| Device | DeviceManager 状态门控、PointManager 失败路径传播、PointBatchService CSV 解析/模板/地址递增/导出往返 |
| Security | WriteGuard 三级门控全路径、登录限流、RBAC 策略、JWT 生成 |
| Protocol | Modbus 地址解析、批量规划、S7 批量读能力、OPC UA 地址解析、ReliableProtocolDriver 重试 |
| Persistence | Sqlite 存储批量写、outbox 两阶段、迁移幂等、磁盘保护判定 |
| Desktop | EventBridge、路径配置、桌面配置持久化 |

## 7. 验证纪律

- 关键逻辑改动走**红绿对照**：先确认新增测试在旧代码上红，再实施修复转绿；证据落 验证记录/ 或 notes/worklog。
- 可证伪：断言外部行为（值、状态迁移、消息发布），不依赖实现细节。
- 独立可复现：CI + 原始输出落盘。
- 收尾：构建（`dotnet build NitroGateway.slnx`）+ 全量测试。
