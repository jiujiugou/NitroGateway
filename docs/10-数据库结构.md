# NitroGateway 数据库结构（FluentMigrator 迁移）

> 生成时间: 2026-08-16 | 来源: `src/NitroGateway.Persistence/Migrations/M001~M012` | 库结构变更一律走新迁移，不手动改表

## 一句话

SQLite 单库共 **9 张业务表**：时序数据（`measurements`）、转发缓冲（`forward_buffer`）、配置（`devices`/`points`）、告警（`alarm_rules`/`alarms`）、系统同步（`app_meta`/`config_sync_outbox`/`sites`）；另由 FluentMigrator 自动维护 `VersionInfo` 版本表。

## 命名约定（重要）

- `M003` 的 `devices`/`points` 列名为 **PascalCase**（`Id`/`DeviceId`…），后续迁移追加的列也沿用 PascalCase（`UpdatedAt`/`IsDeleted`/`SiteId`）；
- 其余表（`M001/M002/M005/M006/M010/M012`）为 **snake_case**；
- 原因（ADR-002 P3-1）：M003 已执行过的列名改动会破坏现有库结构，故保留现状不再改；新增表统一 snake_case。
- 时间列统一为 **O 格式 UTC 字符串**（字典序 = 时间序，可用字符串比较查询）。

## 1. 时序数据

### `measurements`（M001 + M007 + M009）— 每行 = 一次采集快照

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string PK | 快照 ID |
| `device_id` | string NN | 设备冗余标识 |
| `point_id` | string NN | 点位冗余标识 |
| `point_name` | string NN | 点位名 |
| `raw_value` | string 可空 | 原始值 |
| `value` | double 可空 | 工程值 |
| `data_type` | string NN | 真实类型（Bool/Int/String…，ADR-001 P1-5）|
| `timestamp` | string NN | O 格式 UTC |
| `quality` | string NN | 质量码（Good/Bad/Uncertain）|
| `error_msg` | string 可空 | 错误信息 |
| `site_id` | string(100) NN 默认'' | M009 站点列（中心库按站点写入，现场库默认空串）|

索引：
- `idx_measurements_query`(device_id, point_id, timestamp ASC) — 按设备/点位的时间范围查询
- `idx_measurements_timestamp`(timestamp ASC) — 按时间全表清理（PurgeAsync 分批删，M007/ADR-018 P2-1）

## 2. 转发 / 缓冲（北向 MQTT/HTTP）

### `forward_buffer`（M002 + M004 + M008）— 转发缓冲 + 死信

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string PK | 批次 ID |
| `payload` | string NN | `BatchMeasurements` 的 CamelCase JSON |
| `status` | string NN 默认 'Pending' | 生命周期 Pending → InFlight → 删除/DeadLetter |

| `last_error` | string 可空 | 最近一次失败原因（死信展示/排查）|
| `channel` | string NN 默认 'mqtt' | MQTT/HTTP 通道隔离（M008/ADR-011，旧行默认归 mqtt）|

索引：`idx_forward_buffer_status`(status, enqueued_at ASC) — 按状态 FIFO 出队

## 4. 告警

### `alarm_rules`（M005）— 告警规则

`id` PK · `device_id` NN · `point_id` NN · `operator` string(20) NN · `threshold` double NN · `threshold_upper` double 可空 · `duration_seconds` int 默认 0 · `severity` string(20) NN · `message_template` string 可空 · `enabled` bool 默认 true

索引：`idx_alarm_rules_point`(device_id, point_id) — 点位评估加载

### `alarms`（M005 + M009）— 告警记录

`id` PK · `rule_id` NN · `device_id` NN · `point_id` NN · `trigger_value` double 可空 · `threshold` double 可空 · `severity` string(20) NN · `message` string 默认'' · `state` string(20) NN · `first_exceeded_at` string 可空 · `occurred_at` string NN · `acknowledged_at` string 可空 · `resolved_at` string 可空 · `site_id` string(100) NN 默认''

索引：
- `idx_alarms_device_state`(device_id, state) — 活跃告警查询
- `idx_alarms_occurred`(occurred_at DESC) — 历史页倒序展示

## 5. 系统 / 同步

### `app_meta`（M006）— 应用元数据（key-value，当前仅 `app_version`）

`key` string(100) PK · `value` string NN · `updated_at` string NN（迁移完成后由 MigrationRunner 写入）

### `config_sync_outbox`（M010）— 现场待上报变更队列（中心侧保持空，仅现场写）

`id` PK · `entity_type` string(30) NN · `device_id` NN · `point_id` string 可空 · `updated_at` NN

### `sites`（M012）— 站点注册（ADR-036，2026-08-12）

`Id` int64 PK 自增 · `site_id` string(32) NN UNIQUE · `display_name` string(100) NN 默认'' · `source_client_id` string(200) 可空 · `last_seen_client_id` string(200) 可空 · `first_seen_at` datetime NN · `last_seen_at` datetime NN

- Ingest 首见站点写入（upsert），后续只更新 `last_seen`；
- `source_client_id`/`last_seen_client_id` 记录 MQTT 来源指纹（ClientId 含机器名），供同一 siteId 多来源冲突检测；
- Web 站点列表 = sites ∪ measurements ∪ alarms 去重（兼容既有库，站点不因升级消失）。

## 关系与索引汇总

- **关系**：`devices` 1→N `points`（外键）；`points` 1→N `measurements`（冗余 device_id，无外键）；`alarm_rules`/`alarms` 挂点位；`forward_buffer.payload` = 批量数据 JSON。
- **索引共 9 个**：measurements×2、forward_buffer×1、points×1、alarm_rules×1、alarms×2、sites unique×1、VersionInfo 由 FluentMigrator 维护。

## 维护提醒

- 表结构变更 → 新增 FluentMigrator 迁移（`MigrationRunner` 自动执行），**不要**手动 ALTER 或改已执行迁移；
- `*.db`/`*.db-shm`/`*.db-wal` 为运行时文件，不提交、不手动编辑（AGENTS.md 雷区）。
