  定稿 ADR-072（D1~D7：KeepAlive 分类 → 复用 SessionReconnectHandler 保会话 → 订阅恢复复用
  SDK 内置 Transfer→Recreate → DriverState 对齐且不造第二套 Online/Offline → 生命周期清理 →
  回退既有轮询），并按 REMADE 定稿 `AC-opcua-layer3-selfhealing.md`（验收待执行，附 V-1~V-5）。
- **重要发现（供实现者，避免踩坑）**：
  1. docs/07 把 `SessionReconnectHandler.BeginReconnect(ISession, int, callback)` 第二参数写为
     `maxRetries`——SDK 1.5.378.156 实为 `reconnectPeriod`（毫秒），周期性重试而非有界次数；
     ADR-072 已按源码更正。
  2. SDK `Session.Recreate` 内部已实现"先 `TransferSubscriptions`、失败逐订阅 `Create()`"
     （源码核实），官方文档确认 `SessionReconnectHandler` 使用者"no client changes necessary"；
     本项目不得手写第二套订阅迁移（防双 Transfer）。
  3. `SessionReconnectHandler` 回调只回调一次，用 `handler.Session` 引用是否变化区分
     "原地重连保住 vs 重建"；公开清理方法在 1.5.378.156 为 `CancelReconnect()`。
- 范围外未改：ADR-071 提交 `2eb5f35`（层2 实时采集）已入库；层4（安全/凭据）另行立项。
