## 已排查：web 连不上后端（5100 被 VS Code 端口转发占用）

- 现象：vite 代理 `/api`、`/hubs` 到 127.0.0.1:5100 超时；后端 `dotnet run` 明明在跑（绑 0.0.0.0:5100，局域网 IP 可访问）。
- 根因：VS Code「端口转发」（某窗口 NodeService 子进程）占用 127.0.0.1:5100，比 0.0.0.0 更精确 → 本机回环流量被劫持，目标无响应；杀进程会被 VS Code 立即重建，转发未持久化，重启该 VS Code 窗口可清掉。
- 修复（已完成，见 ADR-068）：`web/vite.config.ts` 代理 target 127.0.0.1:5100 → 127.0.0.2:5100（后端绑 0.0.0.0，127.0.0.2 回环同样可达，实测 /healthz 200）。已重启 vite（5173），端到端验证：登录走代理返回 200 + JWT，/hubs 代理可达后端（401）；`npm run build` 通过。
