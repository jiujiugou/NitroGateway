### OPC UA 冒烟 + 断链重连实测 & PointList.vue v2（追加，2026-08-19）

本机无 Prosys + Docker 不可用，改用**进程内 OPC Foundation Server SDK**（1.5.378.145）自起 Server 完成冒烟 + 断链重连实测；同时补齐 PointList.vue 批量生成 OPC UA 起始地址（v2）。全部完成，验证全绿。

#### 实测（集成测试 `OpcUaDriverIntegrationTests`，2 个全绿）
- `SimulationServerScope`：动态端口 + 临时 PKI；`SimulationServer : StandardServer` 注入 `SimulationNodeManager : CustomNodeManager2`（ns=2 下 i=1001 Int32=42 / i=1002 Float / i=1003 Bool / i=1004 String，对齐 Prosys 风格）。
- 路径①：连接 → 读初始值（Int32=42）→ 写 Int32/Float → 回读校验 → Ping → 主动 Disconnect → 重连 → 回读保留值。
- 路径②：Server Stop → 读失败（驱动 `Faulted`）→ 同端口重启 → `ConnectAsync` 重连 → 回读恢复。
- 验证：集成 **45/45** 全绿；单测 **695/695**（690 + 批测 5）；vue-tsc 0 错误。

#### 关键根因修复（代码注释已保留）
1. **Server 证书 → NRE → `BadUnexpectedError`**：进程内 Server 未生成应用证书，None 安全策略下 `CreateSession` 仍走 `ValidateDomains`，证书 null → NRE → 被包装成该错误。修复：`SimulationServerScope.StartServerAsync` 先 `CheckApplicationInstanceCertificates(silent:true)` 生成服务端证书。
2. **Float 写 `BadTypeMismatch`**：测试值 `22.5` 是 C# double，原驱动按 .NET 类型发 Double Variant，服务端 Float 节点拒绝。修复：`OpcUaDriver.WriteAsync` 改用 `ToVariant(point.DataType, value)`（新增 `ToVariant(DataType, object)`，按点位声明做 `Convert.ToSingle/ToInt64/...` 强制类型）。

#### PointList.vue v2（批量生成 OPC UA 起始地址）
