# ADR: 001 数据备份策略

- 日期: 2026-08-05
- 现状: docker-compose 仅定义 gateway-data/gateway-logs 两个数据卷, 无备份机制; SQLite 数据文件 /app/data/nitrogateway.db
- 决策: 使用 SQLite 在线一致性备份(.backup), 脚本 tools/backup.sh, 输出 ./backups/, 保留最近 30 份
- 理由: SQLite 单文件, .backup 可在运行中生成一致性快照; 恢复 = 替换数据文件后重启容器, 简单可靠
- 影响: 需 Docker 环境执行; backups/ 不入 git(.gitignore); 定时执行建议 crontab 每日一次
- 备选:
  - 卷级 tar 快照: 可能捕获写中状态, 一致性无保证 — 已否
  - 数据库导出(JSON/CSV): 丢失 WAL 细节, 恢复复杂 — 已否
- 恢复演练(待在有 Docker 环境执行):
  1. docker compose down
  2. 将 backups/nitrogateway-<时间戳>.db 复制为卷内 nitrogateway.db
  3. docker compose up -d
  4. 验证 /healthz 与数据可查
