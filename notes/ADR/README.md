## 一、为什么读起来乱（结构问题，不是你的问题）

- **一套编号混三种文体**：问题清单（code review，001/003~013/016~022/030…）、设计方案（025/026/033/062）、决策与实测（012/052/053/059…），格式各不相同
- **编号 = 时间轴**：1 → 63 按发生顺序排，不是按主题/重要度；线性读 = 重走一遍开发日记
- **状态字段滞后**：不少 ADR 写「待实施/未提交」，代码其实已落地（054/059/061/062 等），照字面读会误以为没做
- **粒度悬殊**：架构决策（035/053）旁边就是「表格垂直居中」（040/041）
- 已缓解：2026-08-21 起按模块分文件夹，同模块的归一起；但**文体混编**仍要靠「五、模块分组表」的 🎯📖🚫 筛选
